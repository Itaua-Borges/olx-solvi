Design a modern internal company application for Sotero, created as an initiative from the Supply Chain / Procurement department.

The app is an internal platform that allows employees to announce, offer, lend, donate, or sell spare parts, materials, tools, and components that they no longer need, while helping other employees find items they may need.

Main concept:
Imagine an employee has a screw, mechanical component, electrical part, tool, spare material, or other item that is no longer useful to them. Instead of keeping it unused or struggling to find someone interested, they can publish it on this internal platform. Other employees can search, discover the item, and contact the owner directly.

The main goal is:
- Improve communication between employees
- Make internal exchanges easier and more accessible
- Encourage reuse of materials
- Reduce unnecessary waste
- Help employees find parts that may already exist within the company
- Create a simple internal network for borrowing, donating, exchanging, or selling items
- Support the Supply Chain / Procurement area by promoting internal reuse before purchasing new materials

Create the interface as a professional internal corporate application, but friendly and easy to use.

APP STRUCTURE:

1. Home Dashboard
Show:
- Search bar: "Search for a part, material or product..."
- Featured announcements
- Recent items
- Categories
- Quick action button: "Create Announcement"
- Section for "Items near you"
- Section for "Recently added"
- Small statistics such as:
  "120 items available"
  "38 exchanges completed"
  "24 items reused"

2. Create Announcement
Create a simple multi-step form where the employee can enter:
- Product name
- Product code
- Reference / part number
- Category
- Quantity
- Condition
- UVS / unit or department
- Type of transaction:
  Sell
  Lend
  Donate
  Exchange
- Price, if applicable
- Description
- Photo upload
- Location / UVS
- Contact preference

Make this form extremely simple and accessible.

Example:
Product: Hexagonal Screw
Product Code: SC-00125
Reference: M8x40
Quantity: 15
UVS: Salvador
Condition: New
Transaction: Donation
Description: "I have 15 units that are no longer needed. Available for anyone in the company who needs them."

3. Item Details Page
Show:
- Large product image
- Product name
- Product code
- Reference
- Quantity
- Condition
- UVS
- Seller / owner
- Transaction type
- Description
- Date published
- Contact button
- "I am interested" button

Add a direct communication feature:
"Chat with owner"

4. Internal Chat
Create a simple internal messaging system where employees can communicate directly about the item.

Example:
Employee A:
"Hi, do you still have 5 units available?"

Employee B:
"Yes, I still have them. I can leave them at the Supply Department."

Include:
- Text messages
- Item preview at the top
- User profile
- Notification when a new message arrives

5. Search and Filters
Allow users to search by:
- Product name
- Code
- Reference
- Category
- UVS
- Availability
- Transaction type

Filters:
- For sale
- For lending
- Donation
- Exchange
- Available nearby

6. My Announcements
Employee can see:
- Active announcements
- Completed exchanges
- Reserved items
- Expired announcements
- Edit announcement
- Remove announcement

7. Notifications
Examples:
"Someone is interested in your item."
"You received a new message."
"Your announcement has been published."
"An item matching your search was added."

VISUAL DESIGN:

Use a professional corporate style inspired by modern enterprise applications.

Use:
- Dark navy / deep blue background elements
- White and light gray surfaces
- Subtle green accents for successful actions
- Rounded cards
- Clear typography
- Minimal icons
- Strong visual hierarchy
- High contrast
- Spacious layout
- Responsive design

The app should feel modern, practical, trustworthy, and easy to navigate.

ACCESSIBILITY:

Accessibility is an important part of the project.

Include:
- Large readable text
- High color contrast
- Clear buttons
- Simple navigation
- Icons combined with text
- Clear status indicators
- Accessible form labels
- Easy-to-understand language
- Keyboard-friendly interaction
- Avoid excessive visual clutter

USER EXPERIENCE:

The platform should require very few steps to publish an item.

The primary user flow should be:

Employee has an unused part
→ Opens the app
→ Clicks "Create Announcement"
→ Adds product information
→ Uploads a photo
→ Publishes
→ Another employee finds the item
→ Clicks "I am interested"
→ Starts a chat
→ Exchange / sale / loan is arranged

Create the following screens in the Figma project:

1. Login
2. Home Dashboard
3. Search Results
4. Item Details
5. Create Announcement
6. My Announcements
7. Notifications
8. Internal Chat
9. User Profile

The final design should look like a real internal Sotero application, not a generic marketplace.

Possible app name:
"Sotero Conecta"
Subtitle:
"Reaproveite. Compartilhe. Encontre."

The overall concept should communicate:
"Before buying something new, check whether someone inside the company already has it."
